# ЛР2: намеренно заложенные дефекты в /todo

Список для отчёта («заложено N, найдено M»). Код: `templates/todo.html`. Результат прогона 21.10.2026: найдено 8 из 8, плюс 1 незаложенный (BUG-09).

| # | Дефект | Ожидаемое поведение | Причина в коде | Severity | Найден |
|---|--------|---------------------|----------------|----------|--------|
| 1 | Добавляется задача из одних пробелов | Пустая или пробельная задача не добавляется | проверка `input.value === ''` без `trim()` | Minor | BUG-06 |
| 2 | Enter в поле ввода перезагружает страницу, задача не добавляется | Enter добавляет задачу | у формы нет обработчика `submit` | Major | BUG-05 |
| 3 | «Удалить» удаляет следующую задачу; последнюю удалить нельзя | Удаляется выбранная задача | `remove(i + 1)` | Critical | BUG-01 |
| 4 | Счётчик «Осталось» не меняется при отметке задачи | Счётчик пересчитывается сразу | в обработчике чекбокса нет `updateCounter()` | Minor | BUG-07 |
| 5 | Отметка «выполнено» сбрасывается после перезагрузки страницы | Статус сохраняется | в обработчике чекбокса нет `save()` | Major | BUG-04 |
| 6 | HTML/JS из текста задачи выполняется (`<img src=x onerror=alert(1)>`) | Текст выводится как есть | `innerHTML` с `${task.text}` | Critical | BUG-03 |
| 7 | Длинное слово без пробелов вылезает за границы списка | Текст переносится | нет `overflow-wrap` в CSS | Trivial | BUG-08 |
| 8 | «Очистить выполненные» удаляет активные задачи, выполненные остаются | Удаляются только выполненные | инвертирован фильтр `t => t.done` | Critical | BUG-02 |
