# ЛР2. Исследовательское (ad-hoc) тестирование: список задач

- **Объект:** страница `/todo` учебного стенда (код: `templates/todo.html`).
- **Дата:** 21.10.2026.
- **Окружение:** Windows 11 Pro, Firefox 156.0.1, стенд запущен локально.
- **Длительность сессии:** 30 минут.
- **Миссия (charter):** изучить основные действия со списком (добавление, отметка, удаление, фильтры, очистка, счётчик, сохранение после перезагрузки) и найти дефекты, которые портят или теряют данные пользователя.

## Что работает корректно
- добавление задачи кнопкой «Добавить», очистка поля после добавления;
- кириллица, эмодзи, повторяющиеся задачи;
- сохранение текста задач после перезагрузки;
- фильтры «Активные» и «Выполненные» показывают правильные задачи.
