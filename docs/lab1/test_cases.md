# ЛР1. Тест-кейсы: калькулятор

Общее предусловие для всех кейсов: стенд запущен (`.venv/Scripts/python app.py`), в Firefox открыта страница http://127.0.0.1:5000/calc.

Прогон: 21.10.2026, Windows 11, Firefox 156.

---

### ТК-01. Сложение двух целых чисел
- **Тип / приоритет:** позитивный / высокий
- **Требования:** ТР-1, ТР-5
- **Шаги:**
  1. В поле «Первое число» ввести `2`.
  2. В списке «Операция» выбрать `+`.
  3. В поле «Второе число» ввести `3`.
  4. Нажать «=».
- **Ожидаемый результат:** выводится «Результат: 5», сообщения об ошибке нет, поля содержат `2`, `+`, `3`.
- **Фактический результат:** «Результат: 5», поля сохранены.
- **Статус:** Pass

### ТК-08. Очистка кнопкой «C» после ошибки
- **Тип / приоритет:** позитивный / средний
- **Требования:** ТР-10
- **Предусловие:** выполнен ТК-05 (на странице сообщение «Деление на ноль невозможно», в полях `5`, `÷`, `0`).
- **Шаги:**
  1. Нажать «C».

- **Фактический результат:** поля пустые, операция «+», результата и ошибки нет.
- **Статус:** Pass

### ТК-09. Умножение двух максимальных по модулю чисел
- **Тип / приоритет:** негативный (граничный) / средний
- **Требования:** ТР-4, ТР-5
- **Шаги:**
  1. Ввести `999999999` в первое поле.
  2. Выбрать `×`.
  3. Ввести `999999999` во второе поле.
  4. Нажать «=».
- **Ожидаемый результат:** «Результат: 999999998000000001» (точное значение).
- **Фактический результат:** «Результат: 999999998000000000», последняя цифра потеряна.
- **Статус:** **Fail**
- **Причина:** числа переводятся в `float` (двойная точность, около 15–16 значащих цифр), а результат имеет 18 цифр.
